# 干员技能参考（模块2）

职责：提供基建技能原文真源，并按需解释少数高频误读技能的特殊机制。根目录快照由 [RIIC-Web](https://github.com/KnightCodeSquareMatrix/RIIC-Web) 数据**全量生成，请勿手改**；人工维护区为 `释义/` 子目录，歧义消歧两页已迁模块3 [歧义/](../3-组合库/歧义/)。

## 内容导航

| 文件 | 内容 |
|---|---|
| `技能-*.md` ×10 | 按设施分片的技能原文：制造站113 / 贸易站96 / 控制中枢90 / 宿舍88 / 会客室77 / 办公室47 / 发电站42 / 训练室110 / 加工站109 / 回收站6 条技能 |
| `名册.md` | 全部 438 名干员的边界闭包（星级/职业/有技能的设施/所属组） |
| `技能等价组.md` | 90 组「同效不同名」技能（如裁缝·β ＝ 手工艺品·β ＝ 鉴定师的手段）及全部持有者 |
| `类别.md` | 官方术语表 82 条：干员组成员、全局资源（感知信息/人间烟火/木天蓼/热情值/外势/工程机器人等）、特殊叠加规则的权威定义；「异格」附 38 名成员名录（受管增补） |
| [`歧义-子串对`](../3-组合库/歧义/歧义-子串对.md) | 子串同名对 31 组（自动生成，如「临光 ⊂ 耀骑士临光」），已迁模块3 |
| [`歧义-简称合称`](../3-组合库/歧义/歧义-简称合称.md) | 简称合称消歧（推王/德狼/能蕾/银崖等，人工维护）＋官方同名组，已迁模块3 |
| `释义/` | 人工维护的特殊技能释义页（按需新增）：高频误读技能/机制的生效口径，默认以技能或机制为题，误读横跨同一干员多条技能时以干员为题 |

数据规模：干员 438 / 基建技能 778 / 术语 82。数据出处为 [RIIC-Web](https://github.com/KnightCodeSquareMatrix/RIIC-Web)（arkntools 游戏解包数据）。技能分类以官方标签为准（45 个标签）；`operator-skill-text.json`、`skill-terms.json` 为上游清洗数据，仅供脚本消费，本目录不放 JSON 副本。

## 查询与引用

按设施使用 `技能-*.md`；按干员使用 [名册](名册.md)；同效技能使用 [技能等价组](技能等价组.md)；术语使用 [类别](类别.md)；歧义使用 [歧义-子串对](../3-组合库/歧义/歧义-子串对.md) 与 [歧义-简称合称](../3-组合库/歧义/歧义-简称合称.md)；特殊机制误读使用 [释义](释义/)；按功能找干员使用模块3 的 [标签速查](../3-组合库/标签速查.md)。

技能原文按设施分片维护，普通干员与技能查询入口由现有结构化数据及后续索引派生，不为每名干员建立人工说明页。人工解析只覆盖快照与官方术语仍无法回答、且存在高频误读的少数技能或特殊机制，写作骨架见 [tpl-特殊技能释义](../../templates/tpl-特殊技能释义.md)，存放于 `释义/`：默认以技能或机制为题并在页内列出全部持有者，仅当误读横跨同一干员多条技能（替换链、互斥、跨设施联动）时以干员为题；释义页不承载组合归属、替代关系、培养评价或场景推荐——分别归模块3和模块6。

`类别.md` 同时承担模块1「资源组合总览」中全局资源与叠加规则的定义来源。
